# Counter

Turns ```counter code blocks into a button that counts clicks in the note itself.

A plugin for [Flint](https://github.com/cucsijuan/flint). Install it from Settings → Plugins → Browse community plugins, or copy `main.js`, `manifest.json` and `styles.css` into your vault's `.flint/plugins/counter/` folder.
